LOCAL WEBSITE — ORIGINAL SITESUCKER FILES + VIMEO POPUP

From the extracted nickpeterson.co folder run:
  python3 -m http.server 8000

Open:
  http://localhost:8000/harmonica-chimes-zccd.squarespace.com/

This package preserves original Squarespace CSS, HTML and gallery scripts as downloaded, and adds a self-contained Vimeo overlay.
Filenames that SiteSucker stored as mojibake have been restored to their correct Unicode form to match the existing HTML URLs.

Vimeo streaming requires internet and video embed permission.
Squarespace APIs (contact forms, cart, analytics) will not function on a local static server.
Some Squarespace scripts request /scripts/... assets absent from the original SiteSucker download; full gallery behavior is not certified.
